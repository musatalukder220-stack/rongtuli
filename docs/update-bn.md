# RongTuli আপডেট — ধাপে ধাপে সহজ গাইড (বাংলা)

**সবচেয়ে সহজ কথা:** এই গাইডের কাজগুলো আপনাকে নিজে করতে হবে না — অ্যাসিস্ট্যান্ট (Arena) এক কমান্ডে
সব করে দিতে পারে:
```bash
python3 tools/release.py --version 1.1 --note "Remove অনেক ভালো"
```
এটা ভার্সন বাড়ায়, পেজ বানায়, APK বানায়, APK আপলোড করে আর `latest.json` নিজেই আপডেট করে।
গাইডটা রাখা হলো **বুঝে নেওয়ার জন্য** — আর যদি কোনোদিন নিজে করতে চান, তাও যাতে পারেন।

নিচের প্রথম অংশটা **একবারই** করতে হয় (অ্যাসিস্ট্যান্ট করে দিলে আপনাকে কিছুই করতে হবে না),
তারপর প্রতিবার নতুন ভার্সনে হয় এক কমান্ড, নয়তো ছোট্ট ৬ ধাপ।
কোনো সার্ভার, কোনো অ্যাডমিন অ্যাপ কেনার দরকার নেই — সব ফ্রি।

## ✅ আপনার অ্যাপে আপডেট নোটিফিকেশন এখনই চালু হয়ে গেছে

আপনার GitHub (`musatalukder220-stack/rongtuli`) আর টেলিগ্রাম (`t.me/rongtuli_app`) — দুটোই বসানো হয়েছে:

| জিনিস | এখন যা আছে |
|---|---|
| আপডেট-তথ্য | `https://raw.githubusercontent.com/musatalukder220-stack/rongtuli/main/latest.json` |
| অ্যাপের ভেতরে ঠিকানা | `src/js/21-update.js` ও `MainActivity.java` — দুটোতেই বসানো |
| আপলোড করা APK | `https://github.com/musatalukder220-stack/rongtuli/releases/download/v0.10/RongTuli-0.10.apk` |
| এখনকার অবস্থা | `latest.json`-এ version `0.10` = আপনার অ্যাপের সমান, তাই **কেউ আজ "আপডেট" দেখবে না** (ঠিক যেমন হওয়া উচিত) |

বাংলায় পরীক্ষাও করা হয়েছে: version `0.11` লিখে দিলে শীট এসেছে — "A new version is ready · You have 0.10 · new is 0.11",
তারপর **Update** চাপলে ভেতরের পেজ খুলে তিন ধাপ (ডাউনলোড → ইনস্টল → ডেটা থাকবে) দেখিয়েছে। পরীক্ষাটা মুছে আবার `0.10` করে দেওয়া হয়েছে।

### যেটা আপনাকে একবার করতে হবে
1. উপরের **APK লিংক** থেকে ফাইলটা ডাউনলোড করে ফোনে ইনস্টল করুন (`RongTuli-0.10.apk`)।
   আগের অ্যাপ থাকলে তার উপরে বসবে, ছবি/প্রজেক্ট থাকবে।
2. **টেলিগ্রাম চ্যানেলে APK-টা একটা পোস্ট হিসেবে দিন** — যাতে "Update" চেপে আপনার ভক্তরা সেখান থেকেও নিতে পারেন।
   (অ্যাপ আপাতত GitHub লিংক ব্যবহার করছে; চাইলে পরে টেলিগ্রাম পোস্টের লিংকও বসিয়ে দেওয়া যাবে।)
3. এই টোকেনটা (`ghp_...`) কাজ শেষ — GitHub → Settings → Developer settings → Tokens (classic) → **Delete** করে দিন।
   অ্যাপের আপডেট চলতে থাকবে; টোকেন লাগে শুধু নতুন ভার্সন আপলোড করতে (তখন নতুন টোকেন দিলেই হবে, বা পুরোটাই আমি করে দেব)।

### নতুন ভার্সন বের করা (এখন এক কমান্ড, আমি চালাব)
```bash
python3 tools/release.py --version 0.11 --note "Remove অনেক ভালো, নতুন ফ্রেম"
```
এটা ভার্সন বাড়ায় → পেজ বানায় → APK বানায় → GitHub-এ আপলোড করে → `latest.json` আপডেট করে।
আপনার অ্যাপ খোলা মাত্রই সবাই "আপডেট" দেখবে।

## প্রথমে একবার (একবারই করতে হয়)

### ধাপ ১ — টেলিগ্রাম চ্যানেল বানান
1. ফোনে টেলিগ্রাম খুলুন → নিচে কলম/পেন্সিল আইকনে চাপুন (New Channel)।
2. নাম দিন যেমন **RongTuli Photo Editor**, username দিন যেমন `rongtuli_app`.
3. চ্যানেল খুলে উপরে চ্যানেলের নাম চাপুন → **Copy Link** → লিংকটা কোথাও লিখে রাখুন, দেখতে হবে এমন:
   `https://t.me/rongtuli_app`

### ধাপ ২ — একটা ফ্রি Gist বানান (এখানেই "নতুন ভার্সন কত" লেখা থাকবে)
1. ব্রাউজারে যান: `gist.github.com` (GitHub অ্যাকাউন্ট ফ্রি, না থাকলে বানান)।
2. **New gist** চাপুন। Filename দিন: `latest.json`
3. ভেতরে ঠিক এই লেখাটা বসান:

```json
{
  "version": "0.10",
  "link": "https://t.me/rongtuli_app",
  "note": "Remove আরও ভালো, নতুন ফিচার",
  "force": false
}
```

4. নিচে **Create public gist** চাপুন।
5. উপরে ডান দিকে **Raw** বাটনে চাপুন → অ্যাড্রেস বার থেকে পুরো লিংকটা কপি করুন, দেখতে হবে এমন:
   `https://gist.githubusercontent.com/আপনারনাম/............/raw/latest.json`

> ⚠️ এই **Raw** অ্যাড্রেসটা কখনো বদলাবে না। তাই এটা একবার লিখে রাখলে সারাজীবন কাজে দেবে।

### ধাপ ৩ — অ্যাপকে জানান কোথায় খুঁজবে
দুই জায়গায় একটা লাইন করে বসাতে হবে:

1. `src/js/21-update.js` ফাইলে:
```js
Updater.INFO_URL = 'https://gist.githubusercontent.com/.../raw/latest.json';   // ধাপ ২-এর Raw লিংক
Updater.CHANNEL  = 'https://t.me/rongtuli_app';                                // ধাপ ১-এর লিংক
```
2. `android/java/com/rongtuli/photoeditor/MainActivity.java` ফাইলে:
```java
static final String UPDATE_URL = "https://gist.githubusercontent.com/.../raw/latest.json";
```
(এই লিংক না বসানো পর্যন্ত অ্যাপ চুপচাপ থাকে — ভুল করে কাউকে বিরক্ত করবে না।)

তারপর টার্মিনালে:
```bash
cd rongtuli
python3 build.py                 # পেজ বানায়
bash tools/build_apk.sh          # APK বানায়
```

## নতুন ভার্সন বের করার সময় (প্রতিবার এই ৬ ধাপ)

### ধাপ ১ — ভার্সন নম্বর বাড়ান
`src/js/00-util.js` খুলুন, প্রথম দিকে পাবেন:
```js
APP_VERSION = '0.10'
```
এটাকে বানান `'1.0'` (বা `'1.1'`, `'1.2'` …)। এখান থেকেই APK-র নিজের নম্বরও আসে,
তাই নতুন APK পুরোনোটার **উপরে** বসতে পারবে।

### ধাপ ২ — APK বানান
```bash
cd rongtuli
python3 build.py
bash tools/build_apk.sh
```
ফল: `android/RongTuli-1.0.apk` (প্রায় ৩৪ MB)।

### ধাপ ৩ — টেস্ট করুন
APK ফোনে পাঠান → ইনস্টল করুন → খুলে দেখুন ঠিক আছে কি না।
(আগের অ্যাপ ইনস্টল করা থাকলে এটাও ইনস্টল হয়ে যাবে, ডেটা থাকবে।)

### ধাপ ৪ — APK টেলিগ্রামে দিন
টেলিগ্রাম চ্যানেলে APK ফাইলটা পোস্ট করুন, সাথে দুই লাইনের কথা লিখুন ("নতুন কী আছে")।
পোস্টের নিচে **Copy Link** চেপে সেই পোস্টের লিংকটা নিন, যেমন:
`https://t.me/rongtuli_app/12`

### ধাপ ৫ — Gist-এ নতুন নম্বর লিখুন
1. `gist.github.com` → আপনার gist → **Edit**।
2. ফাইলে বদলান:
```json
{
  "version": "1.0",
  "link": "https://t.me/rongtuli_app/12",
  "note": "Remove অনেক ভালো, নতুন ফ্রেম",
  "force": false
}
```
3. **Update gist** চাপুন। (Raw লিংক একই থাকবে — কিছু কপি করার দরকার নেই।)

### ধাপ ৬ — ব্যস, শেষ
যাঁদের অ্যাপে পুরোনো ভার্সন আছে, তাঁরা অ্যাপ খুললেই (দিনে একবার চেক হয়) দেখবেন:

> **নতুন আপডেট এসেছে** — আপনার 0.10 · নতুন 1.0 — Remove অনেক ভালো, নতুন ফ্রেম
> [ আপডেট ]  [ পরে ]

- **আপডেট** চাপলে ভেতরে ছোট একটা পেজ খোলে — সেখানে তিন ধাপ লেখা থাকে কীভাবে ইনস্টল করবেন;
  তারপরের বোতামে চাপলে টেলিগ্রাম/ব্রাউজারে আপনার লিংকটা খুলে যায়, সেখান থেকে APK নামে।
- **পরে** চাপলে ওই ভার্সনের জন্য চুপ হয়ে যায়; পরের ভার্সন এলে আবার জানাবে।

## মনে রাখার কথা

| কথা | কারণ |
|---|---|
| **একই keystore দিয়ে সবসময় সাইন করুন** (`android/keys/rongtuli.keystore` + `password.txt`) | অন্য চাবি দিয়ে সাইন করা APK পুরোনো অ্যাপের উপরে বসে না, ফোন "App not installed" বলে |
| keystore আর password.txt কখনো ডিলিট/শেয়ার করবেন না | এটা হারালে আর কখনো আপডেট দিতে পারবেন না, সবাইকে আবার নতুন করে ইনস্টল করতে হবে |
| `version` আগেরটার চেয়ে **বড়** হতে হবে | `0.10` > `0.9` (দশমিক ধরে তুলনা হয়), `1.0` > `0.10` |
| `force: true` শুধু জরুরি ভুল ঠিক করতে | তখন "পরে" বোতাম থাকবে না, বারবার দেখাবে |
| Gist-এ শুধু **Edit** করবেন, নতুন gist বানাবেন না | নতুন বানালে লিংক বদলে যাবে, অ্যাপ পুরোনো ঠিকানাতেই খুঁজবে |

## কাজ না করলে কী দেখবেন

| সমস্যা | সমাধান |
|---|---|
| অ্যাপে আপডেটের খবর আসছে না | `latest.json`-এ `version` আগেরটার চেয়ে বড় কি না দেখুন; Gist-এর Raw লিংকটা ব্রাউজারে খুলে দেখুন ঠিক JSON দেখাচ্ছে কি না; অ্যাপ এক দিনে একবার চেক করে, তাই ফোনের তারিখ এগিয়ে দেখতে পারেন |
| "App not installed" | পুরোনো অ্যাপটা আনইনস্টল করে নতুনটা দিন (তবে তার আগে keystore একই কি না দেখুন) |
| পেজ খুলছে কিন্তু বোতামে লিংক খুলছে না | `link` অবশ্যই `https://` দিয়ে শুরু হতে হবে |
| আপডেট চেক একদমই বন্ধ করতে চান | `Updater.INFO_URL = ''` করে দিন, অথবা Gist-এ `version` পুরোনোই রাখুন |
