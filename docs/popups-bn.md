## পপআপ ১ — প্রথমবার খোলার "Welcome" কার্ড

**কখন:** অ্যাপ প্রথমবার খোলা হলে, আর **প্রতিবার নতুন ভার্সন ইনস্টল** করার পর একবার।
দেখতে ঠিক আপনার পাঠানো ছবির মতো: অ্যাপের লোগো, নীল **Welcome** পিল, `@rongtuli_app`, "Thanks for choosing RongTuli!…", **Don't show this again** টিক, **CLOSE** ও সবুজ **JOIN NOW**।

- **JOIN NOW** → `t.me/rongtuli_app` খুলবে (Telegram)।
- **CLOSE** → কার্ড সরে যাবে, অ্যাপ চলবে; পরের ইনস্টলে আবার আসবে।
- **Don't show this again** টিক দিয়ে CLOSE করলে → **আর কখনো আসবে না** (ফোনে মনে রাখে)।

## আপনি পাবলিশ করবেন যেভাবে (৫ ধাপ)

1. **`RongTuli-1.1.apk` ফোনে ইনস্টল করুন** (লিংক উপরে) — পুরোনোটার উপরে বসবে, ছবি/প্রজেক্ট থাকবে। খুলে দেখুন: Welcome কার্ড আসছে কি না।
2. **MediaFire-এ APK তুলুন** (চাইলে) → Copy link। অথবা উপরের GitHub লিংকটাই ব্যবহার করুন।
3. **টেলিগ্রাম চ্যানেলে নতুন পোস্ট**, ঠিক এই ছাঁচে:
```
RongTuli 1.1
Faster Remove, new frames
https://github.com/musatalukder220-stack/rongtuli/releases/download/v1.1/RongTuli-1.1.apk
```
(১ম লাইনে নাম+নম্বর = সিগন্যাল, ২য় লাইন = নোট, ৩য় লাইন = ডাউনলোড। লিংকের জায়গায় শুধু "Download" লেখার পেছনে লিংকও চলবে।)
4. **চাইলে APK ফাইলটাও** পোস্টে সংযুক্ত করুন।
5. **`latest.json` আপডেট** (ঐচ্ছিক, শুধু ওয়েব-ভার্সনের জন্য): version `1.1` + লিংক। নিজে না করতে চাইলে বলুন, আমি করে দেব (এক কমান্ড)।

> 🔴 **একটা বড় সতর্কতা:** ব্লকিং কার্ডে "পরে" নেই। ভুল/ভাঙা লিংক পোস্ট হয়ে গেলে ব্যবহারকারীরা আটকে যাবে (ডাউনলোডও না, অ্যাপও না)। তাই **পোস্ট করার আগে লিংকটা নিজের ফোনে একবার খুলে দেখুন**। আপনি বলেছিলেন গোপন রাস্তা রাখব না — তাই রাখা হয়নি; চাইলে পরে যোগ করা যাবে।

## সত্যি কথা

- **যাদের হাতে ১.০ আছে, কেবল তারাই** এই পপআপ দুটো পাবে। ০.৯-এ এটা নেই। তাই ১.১ APK টা যত বেশি মানুষ পাবে, তত ভালো।
- **অ্যাপ না খুললে পপআপ আসবে না** (পুশ-সার্ভার নেই)। অ্যাপ খোলা মাত্রই চেক হয়, আর ফিরে এলেও চেক হয় (৮ মিনিটের বেশি হলে)।
- **Java অংশটা এখানে চালানো যায় না** — `setLock`/`quit` কম্পাইল হয়েছে, কিন্তু **ফোনে Back বোতাম একবার নিজে চেপে দেখুন** (প্রথম চাপে টোস্ট, দ্বিতীয়তে বের হওয়া)।
- `latest.json` GitHub-এর raw হোস্টে কয়েক মিনিট পুরোনো থাকতে পারে — তাই অ্যাপ এখন **raw আগে**, jsDelivr ব্যাকআপ হিসেবে পড়ে।
